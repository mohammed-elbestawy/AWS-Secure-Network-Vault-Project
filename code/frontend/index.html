What happens to your secret

  1. Encrypted here. Your browser encrypts it with AES-256-GCM before anything is sent.
  2. Stored as noise. The server keeps only the encrypted blob and a timer. It never receives the key.
  3. Destroyed on read. The first successful open deletes it. Unopened secrets are purged when they expire.
