Architecture

Layers

Edge

CloudFront with a private S3 origin (OAC), WAF managed rules and a rate limit, Shield Standard, Route 53 health check.

Network

VPC with public, app and data tiers, NACLs and security groups on every tier, NAT instance, VPC endpoints.

Connectivity

VPC peering, Transit Gateway hub-and-spoke, PrivateLink for one service, WireGuard tunnel to a simulated office.

Application

Flask API on a private EC2 instance, MySQL on RDS in subnets with no internet route, AES-256-GCM in the browser.

Access

Session Manager over interface endpoints, Parameter Store for the database password, a least-privilege IAM policy.

Detection and response

Flow Logs with Athena, Traffic Mirroring, CloudWatch alarm with SNS email, a rehearsed isolation and evidence runbook.
